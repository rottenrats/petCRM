# CRM-система (Pet Project)

**Описание:**  
Проект представляет собой CRM систему с регистрацией компаний и пользователей.  
Реализована ролевая модель доступа и система приглашений.

**Стек технологий:**  
- PHP  
- Laravel  
- MySQL  
- Git  
- MVC  

**Функциональность:**  
- регистрация компании с созданием владельца (`Owner`)  
- создание основного счёта компании (`Account`)  
- сервисный слой для бизнес-логики  
- транзакции для атомарных операций  
- ролевая модель доступа:  
  - Owner: полный доступ, приглашает пользователей и администраторов  
  - Admin: ограниченный доступ, приглашает только пользователей  
  - User: базовые права  
- политика доступа через Laravel Policies  
- система приглашений (email через mailer)  

**Архитектура / Architecture:**  
Route → Controller (с Request) → Service → Model

**Цель:**  
Практика backend-разработки на Laravel и построение структуры реального проекта.
